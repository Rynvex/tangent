package domain // import "github.com/Rynvex/tangent/domain"

Package domain holds the pure types and logic of tangent's tree-structured
conversations: lines and messages, branches and their background packs,
conclusion cards, notes, chapters, rolling summaries and the turn prompt.

Nothing here does IO. The package imports only the standard library and
github.com/google/uuid, so the store, the engine and any host can share it.
Most of it was ported from 宿主 (internal/service, Step 7/8); see
docs/devlog/S1-domain.md for what changed on the way.

    the conversation (pack, capsule, card notice, notes, goal, summary, host

    message are not counted. The engine's shared budget measures each feature's
    share with it.

func EstimatePackTokens(s string) int
    EstimatePackTokens is a conservative token estimate for pack text. Words
    of ordinary length cost a quarter token per ASCII character; a long run of
    non-space characters that is mostly ASCII (hashes, base64, minified JSON,
    URLs, long identifiers) costs three quarters of a token per character,
    because such strings tokenise into many short pieces. CJK costs a token
    and a half per character and any other non-ASCII character a whole token.
    For the text kinds listed it stays at or above half a token per character;
    it is an estimate, not a guarantee for every possible string.

func EstimateTokens(s string) int
    EstimateTokens approximates the token count of s: a CJK character (including
    full-width punctuation) counts as one token, every other character as a
    quarter token.

    NormalizeBranchExcerpt trims the selected text and reports whether it is
    within the excerpt limit. It is not required to be a substring of the anchor
    message: the browser shows rendered Markdown, so the selection need not
    match the stored text byte for byte.

func NormalizeBranchPurpose(purpose string, l BranchLimits) (string, bool)

    non-empty and within the purpose limit.

func NormalizeCriteria(criteria []string, l DivergeLimits) ([]string, error)
    NormalizeCriteria flattens the operator's criteria, drops repeats (ignoring
    case) and checks their number and length; none is fine (the model proposes
    them).

func NormalizeFoldSummary(summary string, l FoldLimits) (string, error)
    NormalizeFoldSummary trims a summary and refuses one over the limit;
    "" means none was given.

func NormalizeFolder(folder string) (string, error)
    NormalizeFolder trims a folder name and removes its control characters;
    "" means unfiled. Longer than FolderMaxRunes, or the reserved FolderUnfiled,
    is invalid_input (field folder).

func NormalizeGoalText(text string, l GoalLimits) (string, error)
    NormalizeGoalText flattens a goal to one line and checks it is not empty and
    not longer than the limit.

func NormalizeGroupTitle(title string, l GroupLimits) (string, error)
    NormalizeGroupTitle flattens a title to one line; it may not be empty.

func NormalizeLeaf(in LeafInput, l LeafLimits) (LeafInput, []LeafProblem)
    NormalizeLeaf neutralises a leaf (the line flattened to one safe line,
    the body cleaned like card text) and checks its kind and lengths.

func NormalizeMemoText(text string, l MemoLimits) (string, error)
    NormalizeMemoText trims a memo's text and checks it: not empty, within the
    limit. Line breaks are kept (a memo may be several lines); Windows line ends
    become "\n".

func NormalizeRelationKind(kind string) (string, error)
    NormalizeRelationKind trims a kind given on create: empty is related;
    anything but the four kinds is invalid_input.

func NormalizeRelationLabel(label string, l RelationLimits) (string, error)
    NormalizeRelationLabel flattens a label to one line; it may be empty.

func NormalizeSearchQuery(query string) (string, error)
    NormalizeSearchQuery trims a query and checks its length: at least
    SearchQueryMinRunes (invalid_input), at most SearchQueryMaxRunes (too_long,
    field "q").

func NormalizeSeedText(text string, l ParkingLimits) (string, error)
    NormalizeSeedText flattens a seed's text to one safe line and checks it is
    not empty and within the limit.

func NormalizeSeedTexts(texts []string, l ParkingLimits) ([]string, error)
    NormalizeSeedTexts checks a batch of thoughts: 1 to SeedBatchMax of them
    (invalid_input otherwise), each as NormalizeSeedText checks one.

func NormalizeTag(tag string) string
    NormalizeTag is one tag as stored: control characters removed, trimmed,
    leading "#" removed, lower case. "" when nothing is left.

func NormalizeTagKind(kind string) (string, error)
    NormalizeTagKind trims a tag kind and refuses anything else than the five.

func NormalizeTagStatus(status string) (string, error)
    NormalizeTagStatus is the status the operator writes a tag with: empty is
    confirmed; draft puts it back for review as the model's (B15).

func NormalizeTags(tags []string) ([]string, error)
    NormalizeTags normalises every tag (NormalizeTag), drops the empty ones and
    the repeats (first one kept, input order) and refuses a tag over TagMaxRunes
    or more than TagsMax tags with invalid_input (field tags). The result is
    never nil.

func OpenClaims(conflicts []Conflict, purposes map[string]string) []string
    OpenClaims are the conflicts kept as both, one line each.

func OpenLoopStaleAge(days int, l OpenLoopLimits) (time.Duration, error)
    OpenLoopStaleAge is how long an open branch must be idle to be an open loop:
    days (1..365), or the limit's default for 0.

func OrganizeBranchError(field string) error
    OrganizeBranchError refuses a folder or tags given for a branch
    (invalid_input naming the field).

func ParseBranchDraftProposal(output string) (BranchCard, []NoteChange, error)
    ParseBranchDraftProposal is ParseBranchDraft for an output that may also

func ParseFoldSummary(output string, l FoldLimits) (string, error)
    ParseFoldSummary reads a fold job's reply: the summary, trimmed, cut to the

func ParseGoalProposal(output string, l GoalLimits) (string, error)

func ParseGroupSummary(output string, l GroupLimits) (string, error)
    ParseGroupSummary reads a group_summary reply: the summary, trimmed,
    cut to the limit, not empty.

func ParseRelationKind(kind string) (string, error)
    ParseRelationKind trims a kind given on edit: anything but the four kinds,
    empty included, is invalid_input.

func ProtocolMarkers(extra []string) []string
    ProtocolMarkers lists every marker the library parses (with closing forms)

func QuoteUntrusted(text string) string
    QuoteUntrusted renders untrusted multi-line text the way the library quotes

func RebalanceDue(s RebalanceSignals, l RebalanceLimits) (string, bool)

    spinoff, and why.

func RecallScore(similarity float64, age time.Duration, importance int, l MemoryLimits) float64
    RecallScore is relevance × recency × importance: the similarity (not below
    0), a recency weight from 1 (new) down towards 0.5 (halving its excess every
    HalfLife), and importance / 10.

    SearchLikePattern is the ILIKE pattern of a substring query, with the

func SeedPurpose(text string, l BranchLimits) string

func SpinoffMarkerText(title string) string

func SuggestionPayload(raw []byte, l SuggestionLimits) (json.RawMessage, error)

func SuggestionTargetBranch(lineID string) string

func SummaryTokenCount(messages []Message) int
    SummaryTokenCount estimates the tokens of messages, used to decide when to

func SummaryUptoSeq(messages []Message) int64
    SummaryUptoSeq is the cursor a summary over messages records: the seq of the

func TagSourceOf(status string) string
    TagSourceOf is who a tag written with a status counts as: a draft is the

func TopicCutFor(previousTopic string, summary Summary, reported string, input []Message, uptoSeq int64) string
    TopicCutFor decides where a finished summary's topic cut lands, or "" when

func TopicCutMessage(reported string, input []Message) string
    TopicCutMessage picks the message a topic cut lands on: the model's id when

    them (lowest seq). It returns "" when the summary had no messages.

func TransitionLineStatus(from, to string) error
    TransitionLineStatus validates a status change: a turn starts from any
    non-thinking status, a result lands only on a thinking line, and error is
    reachable from everywhere (timeouts, cancelled runners).

func TrimReply(content string) string
    TrimReply is how a stored reply is trimmed: Unicode white space at both
    ends goes. ResolveTurnOutcome and ExtractBranchSuggestions use it, and the
    engine's stream filter mirrors it, so a streamed reply and the stored one
    are the same bytes.

func ValidBranchKind(kind string) bool
    ValidBranchKind reports whether kind is one of the branch kinds.

func ValidBranchOrigin(origin string) bool
    ValidBranchOrigin reports whether origin is one of the branch origins.

    ValidDeltaKind reports whether kind is text, reasoning or tool.

    ValidLeafKind reports whether kind is one of the leaf kinds.

    ValidLineStatus reports whether s is one of the line statuses.

    ValidNoteSection reports whether s is one of the four sections.

    ValidNoteStatus reports whether s is one of the note statuses.

func ValidSeedStatus(s string) bool
    ValidSeedStatus reports whether s is one of the seed statuses.

    ValidSpinoffMode reports whether mode is detach or fresh.

    ValidSuggestionStatus reports whether s is one of the suggestion statuses.

func ValidTagKind(kind string) bool
    ValidTagKind reports whether kind is one of the five tag kinds.

func ValidateBranchCard(card BranchCard, refs BranchCardRefs) (BranchCard, []BranchCardProblem)
    ValidateBranchCard checks a card the operator confirmed and returns it

    or its pack; an excerpt must be a verbatim substring of the message it

func VectorLiteral(v []float32) string
    VectorLiteral renders an embedding as pgvector's text form.

func WantsTopicSummary(in PromptInput, lineTitle string) bool
    WantsTopicSummary reports whether a turn prompt asks for a [TOPIC] line:

    no summary), never on an aside or a spun-off line (its title came with the
    spinoff); on a main line when the operator's message is longer than 20 runes
    or the line has no title, on a branch when its purpose is longer than 25

func ParseBranchDraft(output string) (BranchCard, error)
    ParseBranchDraft extracts the card from a drafting model's output: exactly
    one [BRANCH-CARD] marker followed by exactly one JSON object. Text before

    fence, unknown or duplicate fields or oversized output fail the whole draft.

    a merged attach carries one (invalid_input, field card), an open one must

func SanitizeBranchDraft(draft BranchCard, refs BranchCardRefs) (BranchCard, []string, bool)
    SanitizeBranchDraft repairs what a model drafted instead of refusing it:
    unverifiable evidence and excerpts are dropped, over-long text and lists are
    cut, and every repair is reported. It reports ok=false when nothing usable
    is left (no question or conclusion, or still too long overall).

func (c BranchCard) CappedReferencedIDs() (branchSide, parentSide []string)
    CappedReferencedIDs is ReferencedIDs bounded by BranchCardMaxReferences,
    branch-side ids first: the most lookups one card can cause.

func (c BranchCard) ReferencedIDs() (branchSide, parentSide []string)
    ReferencedIDs lists the message ids a card cites: those that must be
    messages of the branch or its pack, and those that must be main-line
    messages after the fork. Each id is listed once and only when it is a
    canonical UUID (anything else can never name a message). Callers check
    CheckBranchCardShape first and load exactly these before validating.

func BuildBranchPack(in BranchPackInput) BranchPack
    BuildBranchPack assembles the pack. Size order, when over the budget:
    the older digest/summary goes first, then the oldest quoted messages,
    and only last the anchor message itself is cut. Purpose and selected text
    are length-limited at the door and never cut here. Callers that name the
    anchor run in.Check first.

type BranchPackInput struct {
	// Aside quotes fewer recent messages (PackLimits.AsideRecentMessages).
	Aside   bool
	Purpose string
	Excerpt string
	// Messages are the finished main-line messages up to and including the
	// anchor; the one with the highest seq must be the anchor.
	Messages []Message
	// Summary is the main line's rolling summary; it is used only when
	// SummaryUptoSeq (the seq of the newest message it covers) is set and not
	// after the anchor.
	Summary        Summary
	SummaryUptoSeq int64
	// Later are the finished main-line messages after the anchor. They are
	// used only when IncludeLater is set.
	Later        []Message
	IncludeLater bool
	// AnchorMessageID, when set, names the anchor: messages after it (by seq)
	// are ignored, and Check refuses an input whose anchor is missing.
	AnchorMessageID string
	// CardAnchor lets the anchor be a conclusion card among Messages (a
	// follow-up branch on it): the card is quoted as the last message.
	CardAnchor bool
	// ExtraMarkers are host protocol markers removed from the rendered pack
	// besides the library's own.
	ExtraMarkers []string
	// Limits bounds the pack; a field that is not positive means its default.
	Limits PackLimits
}
    BranchPackInput is what the pack is built from.

type Error struct {
	Code    string
	Message string
	Extra   map[string]any

	// Has unexported fields.
}
    Error is a refusal the caller can act on: a stable code, a message for the
    operator and optional extra fields. The codes reuse 宿主's strings
    so a ported frontend tells the refusals apart without changes. The HTTP
    layer maps codes to statuses; this package knows nothing about HTTP.
    The Err* sentinels are shared values: never modify their fields, use AsError
    or NewError for a copy.

func AsError(err error, l Limits) *Error
    AsError turns any domain error in err's chain into a fresh *Error with the
    extra fields 宿主 sent (limits, counts, ids), or returns nil when
    err is not a domain error. The message is the domain error's own text,
    never the wrapping context, so nothing internal leaks. Shared sentinels
    are never modified, and the copy unwraps to the error it was made from,
    so errors.Is(AsError(err, l), ErrX) still holds.

	// Nodes are the proposed tree nodes in order; every input unit Key appears in exactly one node's UnitKeys.
	Nodes []ImportAnalyzeNode `json:"nodes"`
}
    ImportAnalyzePlan is the proposed tree.

func AnalyzeImportDeterministic(in ImportAnalyzeInput) (ImportAnalyzePlan, error)
    AnalyzeImportDeterministic threads the units by their topic words and
    assigns roles, without a model (Source "heuristic"); in is checked first
    (NormalizeImportAnalyzeInput).

    Threading, unit by unit: a unit stays with the previous unit's node when
    that node has no reply yet, when the question opens like a follow-up (那, 如果,
    為什麼, what about…) or names no topic word. Otherwise it joins the node (the
    previous one included) whose questions share the most topic words with its
    question, counting only words in one node's questions (the previous node on
    a tie, else the most recent); when none shares any, the B21 rule keeps it
    with the previous node if it shares a word with that node or the previous
    unit's answer, else it starts a node.

    Roles, node by node in order of their first unit: the first is a chapter;
    a node whose first unit falls strictly inside a chapter's span (between
    its first and last unit) is a detour and becomes a merged branch of the
    innermost such chapter, hung after that chapter's last unit before it;
    any other node of two or more units (or four or more messages) is a chapter;
    what is left is a conversation of its own. A role the import has no room for
    moves as the client's tree defaults do (withinTreeLimits).

func ParseImportAnalyzeOutput(raw string, in ImportAnalyzeInput) (ImportAnalyzePlan, error)
    ParseImportAnalyzeOutput reads a model's analysis reply for in (normalized
    first; its refusal is returned as is). The reply is one JSON object,
    optionally in a ```json fence. The plan is checked strictly and repaired
    where it can be: units are named by their prompt id (U1…) or their key;
    unknown and repeated ones are dropped; a missing unit joins the node of
    the unit just before it (else just after); an unknown role is a chapter;
    a branch's attachToKey must name a chapter node (else the chapter it started
    in, else the latest before it, else the first) and attachAfterUnitKey a
    unit of it before the branch; the limits of an import move roles as the
    tree's defaults do; texts are flattened and cut. A reply that is not such
    an object, has no usable node or leaves out more than half the units is
    ErrImportAnalyzeOutput (the caller then uses AnalyzeImportDeterministic).

type ImportAnalyzeScore struct {
	Hits, Extras, Misses int
	RoleHits, RoleTotal  int
	Nodes, GoldNodes     int
}
    ImportAnalyzeScore is a plan's agreement with a gold: unit pairs the plan
    and the gold both put in one node (Hits), pairs only the plan joins (Extras:
    over-merging), pairs only the gold joins (Misses: over-splitting),
    and the gold nodes whose first unit the plan gave the gold's role (RoleHits
    of RoleTotal, counting gold nodes with a role).

func ScoreImportAnalyzePlan(plan ImportAnalyzePlan, gold []ImportAnalyzeGoldNode) ImportAnalyzeScore
    ScoreImportAnalyzePlan compares plan with gold over the gold's units:
    a unit the plan leaves out is alone, a unit the gold leaves out is ignored.

func (s ImportAnalyzeScore) Add(o ImportAnalyzeScore) ImportAnalyzeScore
    Add is the score of both together (pairs and roles summed).

func (s ImportAnalyzeScore) F1() float64
    F1 is the harmonic mean of precision and recall.

func (s ImportAnalyzeScore) Precision() float64
    Precision is the share of the plan's pairs the gold has; 1 without any.

func (s ImportAnalyzeScore) Recall() float64
    Recall is the share of the gold's pairs the plan has; 1 without any.

func (s ImportAnalyzeScore) RoleAccuracy() float64
    RoleAccuracy is the share of the gold's roles the plan gave; 1 without any.

func (p Prompt) Chat() (string, []ChatMessage)
    Chat renders the prompt for chat APIs: every section, the summary and the
    condensed older history (quoted, as data) in the system string; the recent
    history and the operator's message as messages. System entries are sent as
    user messages, neighbouring messages of one role are merged and the list
    always starts with a user message, as chat APIs require.

    are set, stable + "\n\n" + volatile equals Chat's system string.

type PromptInput struct {
	// Instructions, AgentName and Role describe the assistant; all optional.
	Instructions string
	AgentName    string
	Role         string
	// History is the line's messages before this turn (HistoryBeforeTurn);
	// it is ordered by seq here.
	History     []Message

	Branch *BranchPromptInfo

	Goal string

	OriginCapsule string

	// open both the full and the resume prompt.
	Cards []BranchCardNoticeItem

	// A resume prompt carries it only when NotesChanged.

	Summary        Summary

	// library-rendered block (cards, rules, notes, pack, summary, condensed

	ExtraMarkers []string

	Limits HistoryLimits

	OmitBranchSuggestRules bool

	// WantsTopicSummary); AllowChapterCut allows a [CHAPTER] line (the
	// chapters feature, main line only). Their rules form the trailing
	// SectionReplyLines, not the stable rules.
	RequestTopicSummary bool
	AllowChapterCut     bool
}

type PromptSection struct {
	Key      string `json:"key"`
	Title    string `json:"title"`
	Body     string `json:"body"`
	Trailing bool   `json:"trailing,omitempty"`
}
    PromptSection is one block of the system part of a prompt. Title, when set,
    is rendered as a "## Title" heading (flattened to one line) before Body;
    the built-in sections carry their headings in Body and leave Title empty.
    Body is trusted prompt text: a host that puts untrusted data in it quotes
    that data with QuoteUntrusted or FlattenUntrusted. The built-in keys
    (Section*) are reserved; BuildPrompt renames a host section that uses one.

    Trailing, set by a host on its own section, places it among the trailing
    sections (after the summary, outside the cacheable prefix of ChatBlocks)
    instead of after the notes: for host data that changes every turn,
    which would otherwise invalidate the prompt cache of everything after it.
    The engine honours it when it arranges a turn prompt; BuildPrompt keeps
    every section in Sections.
