package store // import "github.com/Rynvex/tangent/store"

Package store is tangent's Postgres layer: the embedded migrations, the sqlc
queries and every transaction the engine runs. It keeps the invariants of
docs/DESIGN.md §5 (lock order root → parent → child, sets in id order) and
returns domain errors. It never publishes events: every write returns what
changed so the caller can publish after commit.

FUNCTIONS

func CheckFeatures(ctx context.Context, pool *pgxpool.Pool, features ...string) error
    CheckFeatures reports, with an error that says what to run, a feature whose
    extension is missing or not on the search_path, or whose migrations were not
    applied. tangent.New calls it for the features it is given.

func ExpireSuggestions(ctx context.Context, tx Tx, lineIDs []string) ([]domain.Suggestion, error)
    ExpireSuggestions expires, inside a write's transaction, the open
    suggestions about the given lines.

func ExpireSuggestionsOfKind(ctx context.Context, tx Tx, rootLineID, feature, kind string) ([]domain.Suggestion, error)
    ExpireSuggestionsOfKind expires, inside a write's transaction (a TxHook that
    holds the conversation's main line), the open suggestions of one feature and
    kind in the conversation.

func FeatureExtension(feature string) (extension string, ok bool)
    FeatureExtension names the extension of a feature that brings its own
    migrations; ok is false for every other feature (nothing to migrate).

func MarkNotesRevisionSent(ctx context.Context, tx Tx, lineID string, revision int) error
    MarkNotesRevisionSent records, inside a write's transaction (a TxHook),
    the notes revision a finished turn carried. It never moves backwards.

func MarkSuggestionAccepted(ctx context.Context, tx Tx, id string) (domain.Suggestion, error)
    MarkSuggestionAccepted accepts an open suggestion inside another write's
    transaction (a TxHook), after that write's own locks; ErrSuggestionNotOpen
    rolls the write back.

func Migrate(ctx context.Context, pool *pgxpool.Pool) error
    Migrate applies every pending core migration in order, each in its own
    transaction, recording it in tangent_schema_migrations. A Postgres advisory
    lock makes concurrent processes wait for each other instead of racing.
    Tables are created unqualified, in the first schema of the connection's
    search_path.

func MigrateDown(ctx context.Context, pool *pgxpool.Pool, target int) error
    MigrateDown reverts the applied core migrations newer than target, newest
    first; target 0 removes every core table (the version table stays). Feature
    migrations build on the core tables, so when any core step is reverted every
    applied feature migration is reverted first (as MigrateFeaturesDown does);
    a later MigrateFeatures applies them again.

func MigrateFeatures(ctx context.Context, pool *pgxpool.Pool, features ...string) error
    MigrateFeatures installs what the named features need: their extension
    (CREATE EXTENSION IF NOT EXISTS, which needs the right to create it)
    and their pending migrations, each in its own transaction, recorded in
    tangent_feature_migrations. It runs under the same advisory lock as Migrate,
    after it. A feature without migrations is an error, so a typo never passes
    silently.

    The extension is created without a schema, so it lands in the first schema
    of the connection's search_path, like tangent's tables. A host that wants it
    in a shared schema installs it there beforehand (CREATE EXTENSION ... SCHEMA
    ...); an installed extension is then only checked to be on the search_path.

func MigrateFeaturesDown(ctx context.Context, pool *pgxpool.Pool, features ...string) error
    MigrateFeaturesDown reverts every applied migration of the named features,
    newest first. Extensions stay installed.

func ReconcileFolds(ctx context.Context, tx Tx, lineIDs []string) ([]domain.Fold, error)
    ReconcileFolds, inside a write that moved messages between the lines (a
    move, a promotion), moves each drafting or active fold of the lines to the
    line both its ends are on now, and removes one whose ends were split or are
    gone. It returns the folds it changed.

func RecordCoreMigration(ctx context.Context, tx Tx, version int) (recorded bool, err error)
    RecordCoreMigration records that core migration version was applied.

func RecordFeatureMigration(ctx context.Context, tx Tx, feature string, version int) (recorded bool, err error)
    RecordFeatureMigration records that version of feature's migrations was
    applied (feature as in FeatureMigrationsFS, for example "search").

func WithInboxFeatures(ctx context.Context, features []string) context.Context
    WithInboxFeatures makes the line views read with ctx count only the open
    suggestions of these features (the ones on for the caller); without it they
    count every open suggestion.

	Tenant          string
	TargetLineID    string
	SourceLineID    string

	Card            *domain.BranchCard
	Leaf            bool
	ConfirmDeeper   bool
	CreatedBy       string

}
    AttachInput attaches SourceLineID under TargetLineID. Kind and Status are

    (status merged) is checked under the locks; Leaf writes it as the branch's
    confirmed leaf (the leaf feature is on). BuildPack builds the pack once the
    anchor and the purpose are known.

type Store struct {
	// Has unexported fields.
}
    Store runs tangent's transactions over a host's pool.

func New(pool *pgxpool.Pool, limits domain.Limits, opts ...Option) (*Store, error)
    New builds a store over the pool. Limits that cannot work are refused;
    fields left at zero take their defaults.

func (s *Store) ActiveNotes(ctx context.Context, rootLineID string) ([]domain.Note, error)
    ActiveNotes returns the active notes of a conversation by its main line's
    id. The id must come from the store (BegunTurn.RootLineID): there is no
    tenant check here.

func (s *Store) AddMilestone(ctx context.Context, in MilestoneInput, hooks ...TxHook) (ChapterChange, error)
    AddMilestone stores a milestone on a message of the line's conversation,
    under the main line's lock so the cap holds. An archived conversation is
    read-only.

func (s *Store) AppendSystemMessage(ctx context.Context, tenant, lineID string, n SystemNotice, hooks ...TxHook) (AppendedSystemMessage, error)
    AppendSystemMessage appends a host system message to a line under the line's
    row lock (the only lock it takes), after whatever the line holds, a pending
    reply included. A line that is archived, or a branch that (or an ancestor
    of which) has ended, takes none; a line that is gone (another tenant's,
    or a conversation deleted meanwhile) is ErrLineNotFound. The line's activity
    is refreshed.

func (s *Store) ApplyNoteChanges(ctx context.Context, in ApplyNotesInput, hooks ...TxHook) (NotesWrite, error)
    ApplyNoteChanges validates and writes the changes in one transaction:
    a refused change leaves the notes as they were. The revision moves once.

func (s *Store) ArchiveTree(ctx context.Context, tenant, lineID string, archived bool, hooks ...TxHook) ([]domain.LineView, error)
    ArchiveTree archives or unarchives a main line together with every branch
    of its tree, in one transaction under the locks main line → branches in id
    order, and returns the changed lines with the main line first. A branch is
    refused: it ends with discard, not archive.

func (s *Store) AttachLine(ctx context.Context, in AttachInput, hooks ...TxHook) (AttachedLine, error)
    AttachLine attaches a main line, with its tree, as a branch of another
    conversation's line. Refusals: either line unknown (line_not_found),
    the source not a main line, the same conversation or empty (invalid_input),
    either archived (archived), the target answering (source_busy), a line of
    the source tree answering (branch_busy) or drafting (branch_drafting),
    the target a closed branch (parent_closed), the branch limits with the
    source's tree counted, no anchor on the target (move_no_anchor), an anchor
    that is not one (anchor_not_found), a card that is not acceptable.

func (s *Store) AttachTags(ctx context.Context, messages []domain.Message) error
    AttachTags sets the tags of the messages that have one (one query);
    the fisheye reads them for its head starts.

func (s *Store) BeginTurn(ctx context.Context, in BeginTurnInput, hooks ...TxHook) (BegunTurn, error)
    BeginTurn stores the operator's message and a pending assistant message
    and moves the line to thinking, under the line's row lock. It refuses a
    second pending turn (ErrTurnPending) and a branch that takes no turns.
    The cards the turn carries and the notes revision are chosen under the same
    lock and recorded on the pending message, so CompleteTurn marks exactly
    those delivered.

func (s *Store) BranchLineEnded(ctx context.Context, lineID string) (bool, error)
    BranchLineEnded reports whether a line is a branch that has ended, or hangs
    below a branch that ended or a line that was archived. Such a line takes no
    more turns. A main line is never "ended" here.

func (s *Store) BranchPurposes(ctx context.Context, tenant string, lineIDs []string) (map[string]string, error)
    BranchPurposes returns the purpose of each of the tenant's branch lines
    among lineIDs; ids that are not branches (or not ids) are left out.

func (s *Store) BranchSubtree(ctx context.Context, tenant, lineID string) ([]domain.LineView, error)
    BranchSubtree returns the branch line and every line below it, the branch
    first.

func (s *Store) BranchViews(ctx context.Context, tenant string, lineIDs []string) ([]domain.BranchView, error)
    BranchViews reads the outline rows of many branches of the tenant in one
    query, in the order of lineIDs; ids that name no branch of the tenant are
    skipped.

func (s *Store) CancelTurn(ctx context.Context, tenant, lineID, partial string, hooks ...TxHook) (CancelledTurn, error)
    CancelTurn ends the line's pending turn as cancelled: the message keeps the
    partial text the caller streamed so far, meta.cancelled is set, the line
    goes idle. Without a pending turn it changes nothing.

func (s *Store) CancelTurnFor(ctx context.Context, tenant, lineID, turnID, partial string, hooks ...TxHook) (CancelledTurn, error)
    CancelTurnFor is CancelTurn for one named turn: when the line's pending turn
    is another one (the named turn finished and a new one began), it changes
    nothing, so the new turn never gets the old turn's text.

func (s *Store) ClaimBranchDraft(ctx context.Context, tenant, lineID string, hooks ...TxHook) (DraftClaim, error)
    ClaimBranchDraft marks the branch drafting under its line's row lock,
    so no turn can start while the draft reads the conversation, and records a
    card_draft job (a timed-out earlier draft's job is superseded).

func (s *Store) CombineBranches(ctx context.Context, in CombineInput, hooks ...TxHook) (CombinedBranches, error)
    CombineBranches closes the branches (discarded, merged_into the new one),
    opens the new branch and re-hangs their open children on it, in one
    transaction under the locks root → parent → the branches in id order → their
    open children in id order. A child keeps its anchor (the message it forked
    from, which stays on the combined branch; the new branch's pack quotes that
    branch's latest messages) and its depth (the new branch is the combined
    ones' sibling). Refusals: fewer than two, a branch that is not an open
    non-aside child of the parent (invalid_group, branch_closed), one with a
    turn in flight (branch_busy) or drafting, more open children than a parent
    may hold (branch_limit).

func (s *Store) CompleteTurn(ctx context.Context, in CompleteTurnInput, hooks ...TxHook) (CompletedTurn, error)
    CompleteTurn finishes a pending turn, once: a message that is no longer
    pending returns ErrTurnNotPending. The notices follow the reply (their
    seq is after it). A successful turn marks the cards it carried delivered,
    records the notes revision it carried as sent and ends an answered aside.
    The usage is added to the line's totals; the line goes idle or error.

func (s *Store) CreateBranch(ctx context.Context, in CreateBranchInput, hooks ...TxHook) (CreatedBranch, error)
    CreateBranch opens a branch in one transaction: root then parent are locked,
    the limits checked against the counts under the lock, the anchor checked,
    and the branch line and row inserted.

func (s *Store) CreateComparison(ctx context.Context, in CreateComparisonInput, hooks ...TxHook) (ComparisonWrite, error)
    CreateComparison records a drafting comparison and its converge job under
    the locks root → parent → the branches in id order: MinCount..MaxCount
    distinct branches of the parent, open and not asides (invalid_comparison,
    branch_closed); archived conversations are read-only.

func (s *Store) CreateDivergeBranches(ctx context.Context, jobID string, in DivergeInput, hooks ...TxHook) (DivergedBranches, error)
    CreateDivergeBranches ends a diverge job and opens its branches in one
    transaction under the locks root → parent → job, every branch checked as
    CreateBranch checks one (limits, anchor): all of them or none. A refusal
    leaves the job pending for the caller to fail.

func (s *Store) CreateFold(ctx context.Context, in CreateFoldInput, hooks ...TxHook) (FoldWrite, error)
    CreateFold folds a stretch of a line under the line's lock: both ends on
    the line and finished, MinMessages..MaxMessages messages, none pending,
    no overlap with the line's drafting or active folds (fold_overlap) and room

func (s *Store) PutGoal(ctx context.Context, in PutGoalInput, hooks ...TxHook) (GoalWrite, error)
    PutGoal writes a conversation's goal; an archived conversation is read-only.
    Hooks receive the goal (domain.Goal).

func (s *Store) PutLeaf(ctx context.Context, in PutLeafInput, hooks ...TxHook) (domain.Leaf, error)
    PutLeaf writes the operator's leaf (confirmed) over whatever the branch had.
    An archived conversation is read-only.

func (s *Store) ReadyGroups(ctx context.Context, rootLineID string) ([]domain.Group, error)
    ReadyGroups are a tree's active groups whose summary is ready (what the
    fisheye shows in place of their members).

func (s *Store) RebalanceSignals(ctx context.Context, tenant, lineID string, l domain.RebalanceLimits) (RebalanceState, error)
    RebalanceSignals measures a branch: its finished replies, the parent's
    finished replies after the fork, and whether the tree's last l.RecentTurns
    replies are all the branch's. A branch with fewer replies than either
    threshold needs is not measured further. Reads only.

func (s *Store) RecentMessages(ctx context.Context, tenant, lineID string, limit int) ([]domain.Message, error)
    RecentMessages returns the newest limit messages of a line in seq order
    (Limits.HistoryScan when limit is not positive).

func (s *Store) RecordTopicCut(ctx context.Context, tenant, lineID, messageID, topic string, hooks ...TxHook) (TopicCut, error)
    RecordTopicCut stores a topic cut on a message of the line (SaveSummary
    records its own; this is for hosts that summarise elsewhere).

func (s *Store) RecordTurnUsage(ctx context.Context, turnID string, usage domain.Usage) (RecordedUsage, error)
    RecordTurnUsage records the usage of a turn that ended without CompleteTurn
    (cancelled or failed as stale while its run still finished): on the
    message, once, and added to the line's totals. A pending turn is refused
    (ErrTurnPending: CompleteTurn records its usage); an unknown one returns
    ErrTurnNotPending.

func (s *Store) RemoveFold(ctx context.Context, tenant, foldID string, hooks ...TxHook) (FoldWrite, error)
    RemoveFold takes a fold back (removed; its job, if drafting, no longer
    writes) under the lock of its line. Removed or unknown: fold_not_found.

func (s *Store) RenameBranch(ctx context.Context, tenant, lineID, purpose string, hooks ...TxHook) (domain.BranchView, error)
    RenameBranch changes the purpose of a branch (and the title of its line,
    which follows the purpose) under the branch line's lock. The purpose is
    trimmed and must be within Limits.Branch.PurposeMaxRunes. Open and ended
    (merged, discarded) branches can be renamed (B13); a promoted branch (an
    emptied line) and the previous main line are branch_closed, an archived tree
    archived. Snapshots keep the old name: the pack, card and marker messages,
    note, seed and memo labels, spinoff capsules, suggestion payloads. What
    reads the purpose live (card notices of the parent's next turns, fisheye,
    group summaries, AI proposals) uses the new name from then on (DESIGN
    §12.10).

func (s *Store) RenameFolder(ctx context.Context, tenant, from, to string, hooks ...TxHook) (RenamedFolder, error)
    RenameFolder moves every main line of the tenant in folder from (archived
    ones too) to folder to ("" unfiles them), under the locks of those lines
    in id order. Both names are normalised; from must not be empty. The lines'
    activity time does not change.

func (s *Store) RenameGroup(ctx context.Context, tenant, groupID, title string, hooks ...TxHook) (domain.Group, error)
    RenameGroup changes an active group's title.

func (s *Store) ReplyCount(ctx context.Context, lineID string) (int, error)
    ReplyCount counts the finished assistant replies of a line.

func (s *Store) RetryTurn(ctx context.Context, in RetryTurnInput, hooks ...TxHook) (BegunTurn, error)
    RetryTurn starts the line's last turn again when it failed: the line's two
    newest messages, host system messages left aside, must be the operator's
    message and its failed reply. The failed reply stays (status error);
    a new pending reply is added for the same operator message, which is not
    duplicated. Like BeginTurn it runs under the line's lock, refuses a pending
    turn and a branch that takes no turns, and moves the line to thinking.

func (s *Store) SavePartialReply(ctx context.Context, turnID, content string, streamSeq int64) (bool, error)
    SavePartialReply keeps the text streamed so far on a pending reply and the
    delta seq it covers (meta.streamSeq), so a client that reloads gets the
    start of a reply its stream buffer lost. It writes nothing (false) once the
    reply is finished or a later partial is already saved; it takes no line lock
    and publishes nothing.

func (s *Store) SaveSummary(ctx context.Context, in SaveSummaryInput, hooks ...TxHook) (SavedSummary, error)
    SaveSummary stores a rolling summary and its seq cursor under the line's
    row lock and records the topic cut it implies (domain.TopicCutFor over the
    messages after the previous cursor), in one transaction.

func (s *Store) Search(ctx context.Context, in SearchInput) ([]SearchRow, error)
    Search finds the tenant's hits for a query (see SearchInput). It returns
    invalid_input for a missing tenant or a query shorter than the minimum.

func (s *Store) SetMessageTag(ctx context.Context, tenant, messageID string, in TagInput, actor string, hooks ...TxHook) (TaggedMessage, error)
    SetMessageTag writes a tag on a finished operator or assistant message under
    the lock of the line it is on; it replaces any tag, a model's included.
    Confirmed is the operator's (source user); draft is source ai, status draft.
    An archived conversation is read-only.

func (s *Store) SimilarMemories(ctx context.Context, tenant string, embedding []float32, limit int) ([]domain.MemoryCandidate, error)
    SimilarMemories are the tenant's active memories of the embedding's size,
    the most similar (cosine) first, at most limit.

func (s *Store) SpinOffFresh(ctx context.Context, in FreshInput, hooks ...TxHook) (SpunOff, error)
    SpinOffFresh creates the new main line (the source's provider and model)
    with its capsule, copies the notes (CopyNotes), and leaves a marker on the
    source line, under the locks main line → source line. The source tree is
    otherwise untouched. Refusals: an archived conversation, the source line
    answering (source_busy), a message that is not a finished chat message of
    the line (anchor_not_found).

func (s *Store) StartGroupSummary(ctx context.Context, tenant, groupID, feature string, hooks ...TxHook) (GroupSummaryClaim, error)
    StartGroupSummary records a group_summary job (of the feature) for an active
    group and makes it the group's current one (a job started before it no
    longer writes). Hooks receive the GroupSummaryClaim.

func (s *Store) SupersedeMemories(ctx context.Context, tenant string, memoryIDs []string, in MemoryWriteInput, hooks ...TxHook) (SupersededMemories, error)
    SupersedeMemories replaces active memories of the tenant (locked in id
    order) by a new one in one transaction; any of them superseded already →
    memory_superseded. Nothing is deleted.

func (s *Store) TagMessage(ctx context.Context, tenant, messageID, kind, actor string, hooks ...TxHook) (TaggedMessage, error)
    TagMessage writes the operator's confirmed tag; see SetMessageTag.

func (s *Store) TakenSuggestionTargets(ctx context.Context, rootLineID, feature, kind string, keys []string) (map[string]bool, error)
    TakenSuggestionTargets reports which target keys already have an open or a
    dismissed suggestion of the feature's kind in the conversation.

func (s *Store) TenantOrganization(ctx context.Context, tenant string) (domain.TenantOrganization, error)
    TenantOrganization reads the tenant's folders and tags over all its main
    lines (B18.1), without locks: every non-empty folder with its active and
    archived main lines, and every tag of an unarchived main line with how many
    carry it. Both lists are non-nil.

func (s *Store) UndeliveredBranchCards(ctx context.Context, tenant, lineID string, limit int) ([]domain.Message, error)
    UndeliveredBranchCards returns the conclusion cards of a line no turn has
    carried yet, oldest first, at most limit (NoticeMaxPerTurn by default).

func (s *Store) UnsummarizedSize(ctx context.Context, tenant, lineID string) (UnsummarizedSize, error)
    UnsummarizedSize measures a line's unsummarized history without reading the
    messages.

func (s *Store) UntagMessage(ctx context.Context, tenant, messageID string, hooks ...TxHook) (TaggedMessage, error)
    UntagMessage removes a message's tag (whoever wrote it).

func (s *Store) UpdateBranchCard(ctx context.Context, in UpdateBranchCardInput, hooks ...TxHook) (UpdatedCard, error)
    UpdateBranchCard rewrites the card of a merged branch in one transaction
    under the merge's locks root → parent → branch: the card message's content
    and meta.card (its other meta keys stay; delivered is cleared, so the next
    turn of the line carries the card once more), the branch's conclusion
    line and, while it is still the one the merge wrote from the old card (and
    FollowLeaf), the branch's leaf. Refusals: the branch was not merged, a line
    involved is archived, the card is no longer on the parent or the parent has
    ended or has a turn in flight.

func (s *Store) UpdateFold(ctx context.Context, tenant, foldID, summary string, hooks ...TxHook) (FoldWrite, error)
    UpdateFold writes the operator's summary on a fold that was not removed (a
    drafting or failed one becomes active; its job no longer writes) under the
    lock of its line.

    UpdateMemo replaces a memo's text.

    UpdateMemory applies a patch to an active memory (a superseded one is

    UpdateNote changes the text, section or status of a note that has not been

    UpdateRelationLabel changes the label of a relation and keeps its kind;

    WriteLeaf writes a branch's leaf inside a write's transaction (a TxHook).

type Tx interface {
	Exec(ctx context.Context, sql string, args ...any) (pgconn.CommandTag, error)
	Query(ctx context.Context, sql string, args ...any) (pgx.Rows, error)
	QueryRow(ctx context.Context, sql string, args ...any) pgx.Row
}
    Tx is what a hook may run inside a write's transaction.

type TxHook func(ctx context.Context, tx Tx, result any) error
    TxHook runs inside a write's transaction, after the store's own writes and
    before the commit; DeleteTree runs it before deleting, so the rows are still
    readable. result is the value the write is about to return (for example a
    BegunTurn or a MergedBranch), so a hook sees the ids the write generated.
    An error rolls the whole write back and comes back wrapped as "tx hook: …".
    A write that is retried (see runTx) runs its hooks again.

type UnsummarizedSize struct {
	Messages int64
	Chars    int64
}
    UnsummarizedSize is how much a summary of a line would cover: the finished
    messages after its cursor up to the first undelivered card, and their length
    in characters (EstimateTokens never exceeds chars + messages).

type UpdateBranchCardInput struct {

	LineID  string

	FollowLeaf bool

    UpdateBranchCardInput is the edited conclusion card of a merged branch
    and the Markdown that stands for it. The card is already validated and

type UpdatedCard struct {

    UpdatedCard is what a card edit changed: the card message, the branch and,
    when it followed the card, the branch's leaf. ParentLineID is the line that
    holds the card (the branch's parent).
