## 這一版依審查意見改了什麼

1. **S15 收尾分組報錯**：收尾分組沒有主線節點，「← 主線」標籤卻去讀主線的位置，所以出錯。現在收尾分組不顯示這個標籤，地圖也固定從第一欄開始畫，不再跟著選取的節點平移。S15a、S15b 已截圖確認。
2. **S12b 改名失敗**：輸入框保留使用者打的字並維持編輯狀態，按鈕改成「再儲存一次」；節點和地圖上的標題維持原本的。`panel.saveFailed` 改成「沒有存成：{reason}。標題還是原本的，可以再按一次儲存。」
3. **紀要的完成**：紀要條目左邊加上勾選框（觸控時可點範圍 44），勾選後文字劃掉、底色變淡，並寫上完成時間；選單也加了「標成完成」。備忘沒有完成。已寫進元件狀態表（NoteItem、NodeNotes 的 focus、錯誤、唯讀、減少動態），也補了中英文用語。
4. **S4b 順口問說明**：改成「順口問 7 天後就清除，不值得改名」，並註明紀要出處寫「順口問・{目的}」。
5. **S14b 標籤被切掉**：分隔線疊到面板上方，最窄提示改放在握把上方、往內側延伸，整段文字都看得到。
6. **1280 的預設比例**：視窗寬小於 1440 時，預設 45:55，門檻 640 不變。1280 寬時面板浮在地圖旁邊（S3b、S4、S9 已更新）；1024 寬時地圖區仍小於 640，面板照樣在底部。
7. **S8b「你在這裡」**：節點落在聚焦範圍外時，內容淡到 30%、外框改灰，但「你在這裡」標籤維持全亮。

其他：面板改成只有直向捲動，不會再出現橫向捲軸；「← 主線」標籤寫進了用語（`map.backToMain`）。
