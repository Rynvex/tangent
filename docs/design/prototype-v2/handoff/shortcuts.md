# 鍵盤快捷鍵

⌘ 在 Windows / Linux 為 Ctrl。嵌入宿主時，宿主可以重新指定或停用任何一組；衝突時以宿主為準，命令面板永遠可用。

| 動作 | 按鍵 | 原型 |
|---|---|---|
| 命令面板 | ⌘ K | 可用 |
| 開支線（掛在最後一則或選取處） | ⌘ B | 可用 |
| 停車（輸入框內容） | ⌘ ⇧ S | 可用 |
| 記進紀要（選取文字） | ⌘ ⇧ N | 規格 |
| 回主線 | ⌘ [ | 可用 |
| 回上一層 / 關閉對話框 | Esc | 可用 |
| 切換側欄 | ⌘ . | 可用 |
| 切換大綱 / 地圖 | ⌘ ⇧ M | 可用 |
| 送出前預覽 | ⌘ ⇧ P | 可用 |
| 送出 | Enter（輸入法組字中不送出） | 可用 |
| 換行 | ⇧ Enter | 可用 |
| 停止回覆 | Esc（串流中） | 規格 |
| 結束並帶回（在支線裡） | ⌘ Enter | 規格 |
| 上一則 / 下一則訊息 | ↑ ↓（focus 在訊息列表） | 規格 |
| 大綱操作 | 見 `interactions.md` | 規格 |
| 地圖：放大 / 縮小 / 符合畫面 | + − 0 | 規格 |
| 地圖：從選取節點拉關聯 | R | 規格 |
